## Observações

- **H (XS-Trucking)** é a referência estrutural mais próxima (revisão V2 com leitura completa: ver `08b_…`), mas tem licença "All rights reserved": **IDEA ONLY — INDEPENDENT REIMPLEMENTATION**, nenhum código. Não é 100% autoritativo (hitch, combustível e hora vêm do cliente).
- **A (Polarix)** é a única referência de forklift e é MIT: atribuição de copyright deve acompanhar código derivado (ver `14_TECH_DEBT_REGISTER.md`, LEGAL-01).
- Onde a coluna "AUST ADVANTAGE" está em branco para ONESYNC/SECURITY, é porque os padrões do AUST foram superados pela referência naquele ponto específico.

- **Dispositivos:** a linha *TRUCKING UI ARCHITECTURE* é proposta de arquitetura; **PHONE ≠ TABLET ≠ NEXUSOS**. O estado real dos três resources é **ARCHITECTURE PENDING SOURCE REVIEW** (doc 19).
- **Route Builder = ADMIN ONLY** (requisito do projeto; no XS confirmado em 3 camadas).
